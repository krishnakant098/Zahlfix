# CSS ownership

- `style.css`: existing visual worlds and authored choreography; the approved design baseline is retained.
- `components.css`: the only owner of navigation, service cards and contact layout, including responsive variants.
- `fallback.css`: progressive enhancement, readable text view, motion preference and failure states.

457 superseded component selector arms were removed from the original stylesheet, not merely overridden. Other historical visual-world rules were retained to avoid an unrequested redesign.
